# Atualizações do Diário de Bordo

Este repositório público distribui somente os artefatos de atualização do aplicativo Diário de Bordo para Windows, desenvolvido por Naldo Tech.

## Conteúdo previsto por versão

Cada lançamento aprovado poderá incluir:

- Instalador NSIS Windows x64, assinado pelo Tauri.
- Assinatura correspondente do instalador (`.exe.sig`).
- Manifesto `latest.json` consumido pelo atualizador.
- Arquivo de checksum e notas da versão.

Os links do manifesto devem apontar para os arquivos públicos do respectivo GitHub Release. A publicação de qualquer versão depende de aprovação do proprietário. Nenhum instalador ou release foi publicado neste repositório nesta inicialização.

## Limites de segurança

- O código-fonte continua no repositório privado [NaldoJr5/di-rio-de-bordo](https://github.com/NaldoJr5/di-rio-de-bordo).
- Não armazenar código-fonte, bancos de dados, backups ou documentos de usuários aqui.
- Nunca armazenar chaves privadas de assinatura, tokens, senhas ou credenciais neste repositório ou em releases.
- A chave pública e a assinatura do pacote podem acompanhar a distribuição; a chave privada deve permanecer em armazenamento protegido fora do cliente e fora deste repositório.
- Como este repositório é público, todos os artefatos publicados nele podem ser baixados por qualquer pessoa.

Este repositório não hospeda dados operacionais do Diário de Bordo nem oferece serviços de sincronização Online.
